# Savor — Your Recipe Journal

A responsive recipe collection built with React and Vite. Add recipes with ingredients, instructions, category, prep time, and servings; search and filter your collection; mark favorites; and edit or delete saved recipes.

Recipes are saved in the browser's local storage, so they remain available in the same browser on the same device. They are not synced between devices.

## Run locally

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite.

## Checks

```bash
npm run lint
npm run build
```
